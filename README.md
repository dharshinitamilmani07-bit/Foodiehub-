##  Features

*  **User Authentication** – User registration and login.
* **Restaurant Discovery** – Browse restaurants and explore their menus.
*  **Food Menu** – View available dishes and their details.
*  **Food Search** – Search for food items and restaurants.
*  **Favorites** – Save favorite food items or restaurants.
*  **Shopping Cart** – Add and manage food items.
*  **Order Management** – Place orders and view order details.
*  **User Profile** – Manage user information.
*  **Premium UI** – Consistent Forest Green and Champagne Gold colour theme.
*  **Responsive Design** – Designed for a smooth browsing experience across different screen sizes.

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Replace `YOUR_GITHUB_REPOSITORY_URL` with your actual GitHub repository URL.

### 2. Open the Project Folder

```bash
cd foodiehub
```

### 3. Install Dependencies

```bash
python -m pip install -r requirements.txt
```

### 4. Run the Application

```bash
python app.py
```

### 5. Open in Your Browser

```text
http://127.0.0.1:5000
```

##  Project Objective

The main objective of Foodie Hub is to develop a user-friendly food ordering platform that simplifies restaurant discovery, food selection, and order management while providing a modern and attractive user experience.
=======
# Foodiehub-
Foodie Hub is a web-based food ordering and delivery application developed using Python and Flask. It allows users to explore restaurants, browse food menus, search for dishes, add items to their cart, place orders, and manage their profiles through a user-friendly interface.
